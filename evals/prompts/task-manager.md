A task manager: a FastAPI REST API with SQLite storage (tasks have a title, description, status of todo/doing/done, and an optional due date; CRUD plus filtering by status), a command-line client `tasks` built with Typer that talks to the API over HTTP, and a static HTML/JavaScript page served by the API that lists tasks and creates new ones. Python 3.12 managed with uv. Test everything with pytest: the API with FastAPI's TestClient, the CLI by mocking HTTP with respx, and the page by checking the served HTML and its script.
